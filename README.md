# Pixel Perfect Replay

Лендинг новогодних поздравлений на Пхукете с калькулятором стоимости.

## Cloudflare Workers

Тестовый адрес после публикации: `https://phuket-santa.flugerchanell.workers.dev`.
Откройте PowerShell в папке проекта и выполните:

```sh
bun install
npx wrangler login
```

База `phuket-santa-bookings` уже создана в аккаунте `flugerchanell`, а ID указан
в `wrangler.jsonc`. Схема применена через кабинет Cloudflare. Команда миграции
ниже зарегистрирует её в журнале Wrangler и безопасна для этой базы.

```sh
npx wrangler d1 migrations apply BOOKINGS --remote
npm run deploy:cloudflare
```

Откройте личный чат с ботом и нажмите «Запустить». Для настройки webhook
локально заполните `.env`: `PUBLIC_ORIGIN` с адресом выше,
`TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` и `TELEGRAM_WEBHOOK_SECRET`.
Команды `npm run telegram:setup -- chat` и `npm run telegram:setup -- secret`
помогут получить ID чата и сгенерировать секрет. В настройках Worker
добавьте как секреты те же три переменные `TELEGRAM_*` и сохраните изменения.
Затем выполните `npm run telegram:setup -- webhook` на своём компьютере.

Отправьте тестовую заявку с сайта и проверьте карточку в личном чате.
Worker сразу пытается отправить заявку и раз в минуту проверяет очередь повторов.
Заявки на Cloudflare хранятся в D1. Локальная запись использует отдельную SQLite.

## Локальный запуск

Для запуска нужен Node.js 24+. Зависимости
устанавливаются через Bun 1.3+. Первый запуск `bun install` обновит исходный
`bun.lock` с учётом добавленных пакетов Cloudflare.

```sh
bun install
npm run dev
```

## Запуск на своём сервере

```sh
bun install
npm test
npm run build
npm start
```

Чтобы перенести готовую сборку, скопируйте на сервер весь проект вместе
с каталогом `.output/`. В рабочей копии сервера достаточно исходников
и `.output/`, без `node_modules/`. Скопируйте
`.env.example` в `.env` и заполните настройки перед запуском.
В примере сервер слушает `127.0.0.1:3000`. Настройте для него HTTPS
на вашем обратном прокси. Укажите внешний адрес сайта без пути
в `PUBLIC_ORIGIN`, например `https://example.com`.

## Подключение Telegram

1. Создайте бота через `@BotFather` и запишите токен в `TELEGRAM_BOT_TOKEN`.
2. Откройте личный чат с ботом, нажмите «Запустить» или отправьте `/start`.
   Выполните `npm run telegram:setup -- chat` и впишите в `TELEGRAM_CHAT_ID`
   ID своего чата из вывода команды.
3. Запустите `npm run telegram:setup -- secret`. Скопируйте результат
   в `TELEGRAM_WEBHOOK_SECRET` и запустите или перезапустите сайт.
4. Когда HTTPS-адрес заработает, выполните `npm run telegram:setup -- webhook`.
   Отправьте тестовую заявку с сайта и проверьте кнопки в личном чате с ботом.

Кнопки «Подтвердить» и «Отклонить» меняют статус заявки. Команда сама
связывается с клиентом по указанному контакту. Если отправка в личный чат
временно не удалась, сервер повторит её из очереди. Без настроек Telegram
можно проверить запись локально. Перед приёмом заявок проверьте доставку в личный чат.

## Расписание и цены

- Один экипаж, время Пхукета, старт через каждые 30 минут. В обычный день
  последний старт в 22:00, 31 декабря последний старт в 23:00.
- Визит под бой курантов относится к 31 декабря: это последний слот дня,
  00:00 в ночь на 1 января. В данных он хранится как `2026-12-31` + `24:00`,
  на сайте и в Telegram показывается как «Ночь с 31 декабря на 1 января · 00:00».
  Для него доступны только программы на 15 и 30 минут. Заявки со старых
  страниц на `2027-01-01 00:00` сервер переводит в этот слот.
- Дополнительного буфера между заказами нет: время блокирует только сама
  программа. Запись открыта не позднее чем за 2 часа до начала
  (`MIN_LEAD_MINUTES` в `src/lib/schedule.ts`).
- Календарь на сайте зачёркивает даты без свободного времени для выбранной
  программы. Данные отдаёт `GET /api/calendar?program=...`.
- Заявка удерживает время до 30 минут. Команда проверяет адрес и переезд
  перед подтверждением. После отклонения или истечения удержания время освобождается.
- Тарифы и стоимость допов заданы в `src/lib/pricing.ts`. Сумму для заявки
  повторно рассчитывает сервер.
- SQLite сохраняется по пути `BOOKING_DB_PATH`. Для обновлений используйте
  постоянную директорию вне `.output/` и вне публичной директории сайта.

Шрифты Cormorant Garamond и Manrope загружаются через Google Fonts.
